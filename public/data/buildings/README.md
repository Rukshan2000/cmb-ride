# Real-building pipeline

The aim: every building model shown in the simulator should be traceable to a real Colombo building.

## Files
- `worklist.json` / `worklist.csv`: generated by `node scripts/building-priority.ts`. Ranks OSM footprints:
  P3 landmarks, P2 buildings fronting major roads at signalised junctions, P1 other major-road frontage.
  Each row has the OSM id, coordinates, road, OSM link and a street-level imagery link (Mapillary).
- `records.json`: the asset database the game loads. One record per real building; the schema is `BuildingRecord` in `src/map/Landmarks.ts`.
- `models/<id>.glb`: reconstructed models. `refs/<id>/*.jpg`: reference photos (licensed, see below).

## Adding a building
1. Pick the next row from the worklist. Open its OSM link (footprint, any height or levels tags) and its street-level link.
2. Collect reference photos you are allowed to use: your own, CC-BY or CC-BY-SA (Mapillary, Wikimedia Commons), or public domain.
   Record the licence, author and URL for each. Never use Google Street View or Maps imagery, or AI-generated images, as references.
3. Model it in Blender on top of the OSM footprint. The footprint origin is the record's latitude/longitude, the model's +Y is up, and
   north is -Z. Match the floor count, façade bays, balconies, shopfronts and roof, and take colours from the photos.
   Model hidden sides conservatively: plain walls in the same render colour, not invented detail.
4. Export a GLB (Draco or meshopt compression, at most one 1-2K texture atlas) to `models/<id>.glb`.
5. Add or update the record: `model`, the `osm` ids it replaces, its colours, `references`, `source`, and `confidence`:
   - `verified`: compared in-game with `P` (compare view) at the photo's position, and the silhouette, floors and colours match
   - `reference_based`: modelled from photos but not yet compared in-game
   - `approximate`: built from public dimensions or descriptions only
   - `unverified`: placeholder record, no model
6. Compare: open `/?at=<lat>,<lon>,<heading>` (the reference photo's position and bearing), press `P`, and check the result against the photo.

The procedural shell stays for any footprint without a modelled record, so the street layout never changes.
